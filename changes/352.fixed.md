The story journey's "What happened, in order" timeline now names the step in `step_started` and `step_ended` event rows (e.g. "QA started" / "QA ended") instead of showing the bare words "Step started" / "Step ended".

Failure-cause rows on the sprint overview now display a plain-language label for every code: known codes use the site's label table (e.g. "A test's assertion failed"), and codes the site doesn't know (such as 2.0.0 class values like "REVIEW") display "Cause not recorded" instead of the raw code, as the v0.2.0 release promised.
